# Game Scorecard APP

## Uses HTML, CSS and JS

## Requirements

1. Build it from "scratch"
2. Follow the design spec
3. Deploy to the web

## Specification

1.  Display Score For Home and Away Team
2.  Have Buttons (with different score values) to add to score
3.  Update Score to reflect button pressed
4.  Style to reflect Figma Design Image Provided
5.  Tailor to reflect specific game: updated for Rugby Union
6.  Points explanation added

## Concepts Used:

1. button onclick detection
2. flexbox
3. functions
4. The DOM
5. getElementById()
6. textContent
7. Figma
